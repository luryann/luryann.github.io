# luryann.github.io

Static HTML, no framework, no dependencies. The finished pages sit in the
repository root, so GitHub Pages serves this branch directly — no Actions, no
`dist/`.

**Pages setting:** Settings → Pages → Source: **Deploy from a branch**, branch
`main`, folder `/ (root)`.

## URLs

    /                     index.html
    /projects.html
    /experience.html
    /writing.html
    /writing/commits.html
    /photos.html
    /about.html
    /links.html
    /privacy.html

Internal links are relative (`projects.html` from the root, `../projects.html`
from a post), so the site works at the domain root, in a subdirectory, and
straight off the filesystem. `404.html` is the one exception — Pages serves it
for a miss at any depth, so it uses absolute paths.

## Editing

Two ways, both fine:

**1. Edit the built HTML directly.** `projects.html` and friends are ordinary
complete HTML files. Open one, change it, commit. Nothing else needed.

**2. Edit the source and rebuild.** The catch with option 1 is that the head,
nav, and footer are copied into all fifteen files, so a nav change is fifteen
edits. That is what `src/` is for:

    src/layout.html          the shell every page shares (head, nav, footer)
    src/assets/site.css      all styling
    src/assets/site.js       theme toggle, LA clock, academic year
    src/assets/photos/       photos for photos.html
    src/pages/*.html         page bodies
    src/writing/*.html       post bodies, named YYYY-MM-DD-slug.html

    node build.mjs           # Node 18+, rewrites the root HTML files

Then commit the changed output. If you edit built HTML by hand, mirror the change
into `src/` or the next build overwrites it.

## Adding a post

Create `src/writing/2026-09-01-my-post.html`:

    <!--meta {"slug":"my-post","date":"2026-09-01","title":"my post","description":"One line for search results."} -->
    <p>First paragraph.</p>
    <p>Second paragraph.</p>

Run `node build.mjs`. It renders `/writing/my-post.html` and adds the post to
`writing.html`, `sitemap.xml`, and `llms.txt`.

## Adding a page

Create `src/pages/thing.html` with a meta header holding `path`
(`"thing.html"`), `title`, `navKey`, and `description`. To put it in the nav, add
a row to the `NAV` array at the top of `build.mjs`.

## Photos

Drop portrait (9:16) images in `src/assets/photos/`. The build emits one slot per
file, sorted by filename, so name them `01.jpg`, `02.jpg`, and so on. An empty
folder renders eight striped placeholders; `PHOTO_SLOTS` in `build.mjs` sets that
count.

## Generated by the build

`writing.html`, `sitemap.xml`, `robots.txt`, `llms.txt`, `404.html`, `.nojekyll`,
and the footer's "Updated" date (the build date, or `LAST_UPDATED=YYYY-MM-DD`).

## Notes

- No analytics, no cookies, no third-party requests. One `localStorage` key,
  `rl-theme`, documented at `/privacy.html`.
- Theme is applied in a `<head>` script before first paint, so there is no flash.
- `.nojekyll` is there so Pages serves the files as-is.
